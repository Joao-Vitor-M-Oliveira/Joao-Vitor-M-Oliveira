## 🚨 SafeLink Emergencial

**Emergency communication network for disaster scenarios.**

A low-cost communication system designed for situations where traditional internet and cellular networks may be unavailable.

### ⚡ Core Architecture

```text
[ RESCUER ]
     │
     ▼
[ SafeLink ]
     │
     ▼
[ ESP32 / ESP8266 ]
     │
     ▼
[ MESH NETWORK ]
     │
     ├──────► [ NODE ]
     │
     ├──────► [ NODE ]
     │
     └──────► [ RESCUE TEAM ]
```

### Features

* 📡 Local wireless communication
* 🕸️ Mesh networking concept
* 📍 Location sharing
* 🚨 SOS requests
* 🔐 Protected access
* 📱 Web interface
* 💾 Local message history
* ⚡ ESP-based infrastructure
